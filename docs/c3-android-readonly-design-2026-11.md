# C3 Android 只读接入设计提案（草案，默认 No-Go）

本文件是基于 PR #75 的设计提案，不是产品发布许可、契约冻结、功能实现或测试/实测证据。当前仅有隔离 sidecar 解析器；不接加载、UI、播放、联网、持久化或正式发布。现有发现页为本地派生，不将第三方候选混入。实施方案 D.1.2 所列设计门必须完成、独立评审后才进入实际接线；本提案不能绕过 C3 测量、许可、真实试听和发布门禁。

## 建议边界和顺序

1. 先固定跨端 schema、严格字段类型、排序/去重、分类映射、URL 策略及 manifest 绑定语义，并用共享黄金样本核对 Web/Android；#75 解析器仅作实验，不能推定契约已冻结。无效、超限、版本不支持或不一致一律失败关闭。哈希只证明匹配，不证明来源或许可。
2. 冻结可信生产数据与发布决策后，再决定 Android 投递；候选方案是随包资产和独立更新通道，而非混入 radio.txt、四资产协议或用户备份。读取前必须限制输入字节（sidecar 512 KiB、manifest 4 KiB、最多 300 项仅为现有解析实验上限，须跨端确认）；限长应在流读取阶段实施，而非先无界读完再检查。更新需受控来源、代际绑定、完整校验和有界超时；本提案不授权实现联网或打包真实 sidecar。
3. 缺失、损坏、超限、版本不支持、超时均不得影响主库、播放或个人数据；建议只展示经完整验证的最近一次已知良好代，否则安全空态；原子提交与恢复依赖底层文件系统语义和故障注入验证，不能仅凭 rename 宣称断电安全。开关关闭时不读取、不渲染、不联网；明确不可用与回退状态，禁止把 fixture 当真实内容或证据。
4. 默认关闭独立 C3 开关，不能复用既有本地发现总开关以避免改变原功能；测试可注入开关而非持久用户设置。设计阶段不指定生产开关覆盖入口，发布前须审查 release 构建关闭策略、远程投递路径和回滚演练。

## 展示和生命周期待定方案

- 数据只读展示与现有本地派生层清晰区分，不能将 sidecar 伪装成主库或改变原有发现组排序。实验 fixture 如被未来批准，只能存测试源集、离线构建并明确标注，无真实电台/链接，不进入 APK 的正式发布路径。
- 试听在本地离线验证阶段完全禁用；未来正式设计可通过独立临时试听对象显式调用现有播放器，不自动入主库或个人层。播放本身会联网，必须另经网络策略、来源安全及用户操作授权；统计/最近播放/收藏是否记录暂不默认复用现有副作用，需先核对播放器生命周期并冻结语义，不能以直接调用 `startPlay` 代替设计。
- 建议收藏与显式加入都只在用户主动操作后发生；候选 URL 是身份，精确匹配现有台先回绑、禁止同名自动合并，加入时使用现有个人层校验、封顶及冲突处理，失败不丢现有数据。URL 更新、多个源及重复加入的具体回绑与事务语义须跨端评审确定。禁止展示动作隐式写入收藏、最近、统计或个人层。
- 暂不批准 UI 接线：现有发现卡点击直接进入真实播放器，缺少隔离试听及统计、收藏、个人层身份设计；简单挂默认关闭开关不能证明上述副作用安全。

## 先决条件与未来验收

- 测量、许可、人工试听、国内直连及成品门禁按对应 C3 决策执行；缺证据即 No-Go，测试 fixture、JSON 中自报来源、哈希、模拟听取均不是证据。
- 跨端格式及行为测试覆盖无效/错误类型、边界值、多字节、截断/超长流、hash/版本/代错配、重复、非法 URL；验证默认关闭零读取零网络，关闭后原页面与本地发现不变。
- 存储测试覆盖缺失/损坏/写入失败/中断及回退，证明不影响主库和用户数据；对真实文件系统分别验证进程中断与断电假设。生命周期测试覆盖播放、暂停、切台、统计、收藏、显式加入、重复/冲突和身份漂移；各类动作负面断言无隐式写入。
- UI 与设备测试覆盖开关关闭、空态/错误态、无障碍、列表 bounds 与无意联网；JVM 测试不能代替设备验证。生产合入/打开前完成跨端审查、发布和回滚演练，并单独记录证据；本 PR 不宣布这些条件已经满足。
