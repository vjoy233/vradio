# C3 精选上游安全落地门（2026-11）

## 结论

后续用户授权继续编码、离线测试和推荐阈值，不等于下述证据门已达成；尤其真人试听与可证明国内直连仍未验证，生产投放仍为 No-Go。默认关闭的实验接线不等同生产发布。

本分支**不实施生产 C3 接入，不修改 `radio.txt`、四生成资产、`/api/sync`、Android 轻更新、Store 或备份契约**。PR #54 的 C2 证据足以支持继续做有边界的复测和设计，不足以证明可安全发布精选候选。

推荐后续路线是“独立 sidecar + 显式 opt-in”，而不是把第三上游并入主库：候选只进入版本化的 `radio-discovery` sidecar；主库、现有欧美层和同步发布链完全不依赖它；sidecar 缺失、损坏、超时或上游失败时保留上一份或为空，不得清空既有资产。发现卡可试听/播放，但只有用户明确执行“加入个人电台”才写 `my-radio.txt`，并沿用现有 URL 身份、探活和源安全护栏。正式编码前仍须冻结 schema、分类映射、身份/来源字段、manifest 回退、Web/Android 投递和测试契约。

## 现有 C2 证据（PR #54）

固定上游 commit `27dd87329ba9c17248bfaa14467efc27e1ec6cad`，469 个 URL 全量覆盖（前轮 231 + 补测 238）：精确重叠 12（2.56%），合并探活 OK 353/469（75.27%），真正新增且 OK 344；p50 1433ms、p90 4520ms、p95 5414ms；NETWORK 102、SHORT_BODY 14、异常 0。前轮 300 上限样本为 193/231（83.55%），但不是重复试验。

证据边界必须保留：

- `checkDetail=OK` 只证明字节/协议门通过，不证明节目内容、版权、长期稳定性或浏览器/Android 可播。
- ffmpeg 对两个 OK URL 解码 5 秒仅证明解码器收到可解析 MP3；没有真人试听，不能声称“听到”、非静音或内容匹配。
- 出口核查只能佐证中国上海电信出口，不能证明国内直连或每个 Node 目标路径均无透明代理/VPN。
- 台标覆盖率为 0；英文流派尚未完成中文分类与内容质量筛选。

## C3 推荐接受阈值

阈值是**发布门**而非本次测量结果的追认。满足全部条件才允许进入正式 C3 设计/编码：

1. 同一固定 commit、同一测量脚本，在两个不同时间窗口完成两轮全量或等价分层复测；每轮有效结果不少于 90% 候选。
2. 两轮合并 survival（`OK / tested`）≥ **70%**；任一轮不得低于 **65%**。
3. 两轮合并真正新增且 OK ≥ **250**，且精确 URL 重叠率 ≤ **10%**。
4. 合并 p95 探活延迟 ≤ **6000ms**；程序异常 = 0；`SHORT_BODY` ≤ 10%；网络错误需单列，不能伪装成内容失败。
5. 每个拟投放中文分类至少 20 个候选，分类 survival ≥ **60%**；小样本/节日类不得单独形成正式分类。
6. 维护性：固定 commit 可重复拉取，许可证/来源记录完整；sidecar 生成、校验、回退测试全绿。
7. 内容/可播放性人工门：负责人在**可证明的国内直连环境**对每个拟首发分类至少 3 台（至少 10 台代表样本）实际试听，记录可听、内容匹配、版权/品牌风险和失败原因。自动化/ffmpeg/浏览器解码不得替代真人试听；未完成则 C3 仍为 No-Go。

若任一门不满足，结论为暂停在 C2/复测，不得通过降低样本范围或把未测 URL 当失败/成功来凑门槛。

## 风险与未实证项

- 上游 URL 漂移、短期可达不代表长期稳定；单次快照不能推导运营 SLA。
- 精选清单的英文流派、名称和内容需要人工审核，不能由 `#EXTINF` 自动映射后直接发布。
- 版权/品牌合规、台标来源和内容适宜性未实证。
- Android Media3、Web HLS/代理、后台播放、曲讯和多标签生命周期尚无该上游的设备级证据。
- sidecar schema、manifest 版本/回滚、来源 badge、显式加入个人层的身份回绑仍未冻结。

本分支只记录 C3 阈值和安全落地方案，不宣称通过 C3，也不伪称真人试听或可信直连。既有离线回归 `npm test`（30 个测试文件，0 失败）作为基线；C2 报告仍是独立证据目录，生产资产字节不应变化。后续实现 PR 必须先新增 sidecar/schema 与失败隔离测试，再接 Web/Android/UI；不得直接复用未冻结的 `radio-discovery.json` 草案。
