# VRadio 📻

> 零依赖的本地网络电台播放器 —— 国内电台为主、海外电台为辅，无需翻墙，`npm start` 即听；另附安卓原生版（Kotlin + Compose + Media3）。

在浏览器里收听 1600+ 电台：央广/国际台全系、全国省市地方台、音乐/文艺频率，**以及 150+ 个实测可直连的欧美主流音乐台**（Radio Paradise / Classic FM / Heart / Skyrock / SomaFM…）和 CNN / NPR / BBC 等国际新闻台。Web 端核心约 6500 行（前端七模块 + Node 服务端/同步引擎），无 npm 依赖、无构建步骤，不收集任何数据，纯本地运行；安卓版与 Web 版数据同源、格式互通（见 [android/README.md](android/README.md)）。

## 特性

- 🎧 **开箱即听**：预置 1600+ 个电台，按内容分 9 类（**华语音乐 / 欧美音乐** / 亚洲·港台 / 国际新闻·谈话 / 新闻资讯 / 交通广播 / 文艺·生活 / 财经 / 综合·其他），国内源来自社区持续维护的公开直播源列表
- 🎵 **音乐场景优先**：「华语音乐」「欧美音乐」分类置顶；欧美台全部经过国内直连实测过滤，直连可播、无需代理；新闻/谈话类欧美台（CNN/NPR/BBC…）单独归类，不混进音乐
- 🔍 **搜索**：按电台名即时过滤，多词空格分隔全命中（「音乐 北京」→ 北京音乐广播；试试搜「中国之声」「Love」「Capital」）
- ⭐ **收藏**：行首 ☆ 一键收藏，双击电台行 = 播放并收藏（移动端长按行 = 收藏）；localStorage 持久化（记录源 URL，电台改名后自动回绑），可导出为 m3u 备份/换机，导回即恢复收藏
- 🕘 **最近播放**：「最近」分类按播放顺序记录最近 20 台，与「上次收听」续播合一
- 🧭 **发现页**：header「发现」按钮按本地字段派生六分组——精选电台 / 稳定直连（近 30 天质量统计）/ 最近新增 / 最近恢复 / 有曲讯 / 未听过，给「听什么」一点灵感（全本地计算，不联网）
- 📊 **本地收听统计**：按日收听时长仅记录在本机（播放状态机采样），可随完整备份跨机迁移，不上传任何数据
- 🗂️ **网格/列表双视图**：「▦ 网格」大卡片一屏 5 列（手机自动 2 列），「☰ 列表」两行详情限宽居中，选择自动记住
- 🖥️ **桌面新版壳**（2026-11 UI 重设计）：≥1024px 宽度自动切换侧栏布局 + 顶部续听卡（唱片旋转动画、接着上次收听），窄窗口保持紧凑经典布局零变化；`localStorage['feat.uiRefresh']='0'` 可退回旧版
- 🖼️ **台标**：卡片/行首显示电台标志，一眼认台——欧美台来自 Radio Browser 镜像数据（同步时按流 URL 确定性匹配），国内蜻蜓台按「收藏 + 正在播」优先自动解析并永久缓存；**无台标的台出首字母色块兜底**（底色由台名确定性生成，有图无图节奏统一；图片直连加载，坏图自动换色块）
- 🔐 **锁屏/媒体键**：MediaSession API——锁屏、蓝牙耳机、键盘媒体键都能控制播放暂停并显示台名
- 😴 **睡眠定时**：15/30/60 分钟菜单一次点选，到点渐弱停止，睡前听电台不怕忘关（进行中再点取消）
- ⌨️ **键盘与移动端友好**：`↑`/`↓`/`Home`/`End` 列表导航、搜索框 `↓` 直达结果、Tab 单停靠点（roving tabindex）；手机上低频操作收进「⋯ 更多」菜单，header 不挤占内容；维护面板弹窗焦点困窗，Esc 关闭归还焦点
- 🎨 **深浅双主题**：默认跟随系统自动切换；右上 **🌓 按钮**可手动锁定浅色/深色（点击循环：跟随系统 → 浅色 → 深色，选择自动记住）
- 🔄 **多源自动切换**：同一电台常有多个流地址，一个失败自动换下一个，还在蜻蜓 m3u8 与 mp3 直流之间自动换算
- 🎛️ **手动选源**：正在听的多源台点底部栏展开选源浮层，一键切到指定源或「↺ 恢复默认」（⚙ 面板源管理可预选源、启停/上移下移/加标签）
- 🩺 **电台详情中心**：行/卡 ⓘ 打开浮层——本台全部源逐源结构化诊断（结论码/延迟/响应字节/播放模式）+ 源启停/播放/复制地址 + 本台歌曲历史 + 一键恢复默认
- ⚙ **分类与电台维护**：右上「⚙ 维护」面板按个人喜好调整——电台移动到任意分类（含新建）/重命名/隐藏，分类新建/重命名（撞名=合并）/隐藏，全部彻底消失不打扰听歌；每台行内源管理（追加备选源/源启停/手动排序/源标签，逐对象草稿编辑，并发改动给冲突三选）；个人配置存本地（按电台源地址回绑，**同步重建后自动保留**）、可导出/导入 JSON、可一键重置；上游同步导致源地址漂移时面板给出失配清单
- 🛡️ **m3u8 本地代理**：内置同源流代理 + hls.js 分片重写，绕开国内电台 CDN 的 CORS 限制（央广系 CDN 的 CORS 锁了特定 origin，直连必挂——本项目靠代理解决）
- 🔄 **一键同步源**：「同步源」按钮拉取上游最新国内源并按台名重分类 + 逐个实测重建欧美音乐/国际新闻台（约 1 分钟，详见[源的更新与维护](#源的更新与维护)）
- 🩺 **死链体检**：「体检」按钮逐台探测当前列表（服务端检测，无 CORS 限制），✓/✗ 标记；**✗ 失效台默认隐藏且本地持久化（疑似/停运两档：复测连续确认 ≥3 次且首死 ≥30 天才升级「已停运」，复测可达即撤销回归）**，刷新页面不再重现，需要时点「✗ 无效源」开关显示（选择自动记住）；体检会连隐藏的死台一起复查，复活即自动回归
- 🖥️ **零依赖**：Node 内置模块 + 一个本地化的 hls.js，没有 `npm install`，没有构建步骤
- 🧪 **L0–L5 分层测试体系**：`npm test` 零依赖测试总入口（契约比对/单元/服务端矩阵/浏览器 PR 门/夜间演练），详见[开发与测试](#开发与测试)

## 快速开始

```bash
git clone https://github.com/vjoy233/vradio.git
cd vradio
npm start          # 或 node server.js
```

浏览器打开 **http://localhost:8137**，点击任意电台即播。

安卓版（原生 Kotlin + Compose + Media3，含 APK 打包与应用内数据热更新）见 [android/README.md](android/README.md)。

<details>
<summary>环境要求 / 端口与监听修改</summary>

- Node.js ≥ 14（只用内置模块 `http`/`https`/`fs`/`path`）
- 换端口：`PORT=9000 npm start`（Windows PowerShell：`$env:PORT=9000; npm start`）
- 默认仅监听 `127.0.0.1`（安全考虑）；要在局域网其它设备访问：`HOST=0.0.0.0 npm start`，风险自担（`/proxy` 与 `/api/check` 已限制仅公网 http(s) 目标）
</details>

<details>
<summary>不想跑服务器？直接双击 index.html 也能用（功能受限）</summary>

file:// 模式下可直接浏览/播放全库电台（同步随行生成的 `radio-data.js` 提供数据，最后跑过 `npm run sync` 时的快照）；m3u8 代理路径不可用，央广系等仅 m3u8 的电台无法播放（点播时给失败提示不崩坏），同步/体检/添加电台等后端功能不可用。推荐 `npm start`。
</details>

## 使用

- **搜索**：顶部输入框按名称过滤（多个词空格分隔 = 全命中，如「音乐 北京」）；**分类**：顶部 chip 切换（音乐场景用户直接点置顶的「华语音乐」/「欧美音乐」）
- **视图切换**：右上「▦ 网格 / ☰ 列表」——网格为默认（单列长列表太费纵向空间），选择存 localStorage 自动记住
- **台标**：有台标的台在卡片/行首显示标志。来源三级：内置精选硬编码 → `logos.txt`（同步生成，欧美台）→ 运行时解析（**只解析「收藏 + 正在播」的台**：蜻蜓台取频道页封面、其它台查 Radio Browser favicon，结果永久缓存在本地，失败 7 天后自动重试）。图片由 `<img>` 直连加载不走代理，坏图自动换首字母色块
- **无效源电台**：体检标 ✗ 的台默认从列表隐藏（正在播的台例外）；点上方「✗ 无效源」开关可随时显示/隐藏它们，选择存 localStorage 自动记住。死台标记持久化在本地（**疑似 180 天 / 停运永久两档**、按源 URL 身份回绑，上游改名换分类也能对上），刷新页面后依然默认隐藏；再点「体检」会连隐藏的死台一起复查，**复活即自动回归列表**并撤销标记
- **主题**：右上 **🌓** 按钮循环切换 跟随系统 → 浅色 → 深色，选择自动记住；跟随系统档会随系统外观实时切换
- **收藏**：行首 ☆ ⇄ ★，双击行 = 播放并收藏（移动端长按行 = 收藏）；「导出收藏」生成 m3u（其它播放器也能读），导回自动恢复收藏态
- **播放控制**：底部栏 播放/暂停、均衡器动画、🔇/🔊 静音键（取消静音按当前台记忆恢复）、音量拖动即时百分比、当前台与连接状态；😴 按钮开睡眠定时菜单（进行中再点取消）
- **手动选源**：正在听的多源台，点底部栏展开选源浮层——整行点选立即切换（「默认」「正在用」「追加」徽标区分来源），「↺ 恢复默认源」清掉成功源记忆按启发式重播；⚙ 面板源管理里也能在未播态用行内 ▶ 预选源起播
- **每台音量记忆**：电台间电平差异大，音量按台自动记忆——A 台调小后切走再切回自动恢复；没调过的台用全局默认（首次调整时全局锚点随行）。静音是瞬态，不写记忆
- **回到正在播**：列表滚深/切了分类后，点底部栏当前台名即跳回正在播的行并高亮一闪
- **锁屏/媒体键**：⏯ 播放暂停、⏮⏭ 收藏间切台，锁屏/蓝牙通知显示台名 + 台标大图（有台标的台）
- **多标签页防双播**：两个标签页都开时，新开播的一边赢，另一边自动暂停让位（台位保留可续播）
- **歌曲历史**：正在播的台换歌自动记史（每台 12 首）；点底部曲名看本台最近播放，浮层内「导出全部」下载 txt 清单（`歌名（台名 · 时间）`），拿去音乐 App 搜
- **电台详情中心**：行/卡 ⓘ、底部栏 ⓘ 或 ⚙ 源管理「详情」打开——台信息 + 逐源结构化诊断（✓/✗ 结论码、延迟、响应字节、播放模式，与体检同口径）+ 源启停/播放/复制地址 + 歌曲历史 + 一键恢复默认
- **发现页**：header「发现」打开独立浮层——六分组「精选电台 / 稳定直连 / 最近新增 / 最近恢复 / 有曲讯 / 未听过」（本地字段与质量统计派生，点击即播；质量数据随播放与体检自动累计）
- **快捷键帮助**：任意位置按 `?` 呼出全部快捷键一览
- **同步源**：右上「同步源」，约 1 分钟后完成（含欧美台逐个实测；上游失败时自动保留旧列表，不会清空）；完成后状态栏给出 **diff 摘要**（新增 N 台、消失 M 台），消失台里有收藏的会单独点名
- **体检**：切到某分类或搜索过滤后点「体检」，逐台探测（多源任一活即活）、可随时取消，标 ✓/✗，✗ 划线的台基本已下线
- **个人补充列表**：项目根目录建 `my-radio.txt`（同 radio.txt 格式，已 gitignore），页面自动合并、不会被同步覆盖
- **分类与电台维护**：右上「⚙ 维护」打开面板——**分类页**：重命名（改成已有分类名 = 合并，合并后不易拆分）/隐藏/删除自建分类（其中电台自动回到同步默认分类）/新建分类；**电台页**：搜索定位后移动到任意分类（含移动时新建）、重命名（仅显示层，收藏/台标按源地址不受影响）、隐藏（彻底消失，含「全部」和搜索，恢复也在面板）、**行内源管理**（⋯ 展开：追加备选源——流地址漂移的手动救援，先探活拒绝假流/死链、通过才收、只挂台尾不动原源；以及源启停、上移下移手动排序、源标签备注）；单台 ↺ 一键撤回全部个人调整。个人调整只存浏览器本地（localStorage），**按源地址身份回绑——同步重建、上游改名换分类后自动照常生效**；可「导出配置」为 JSON 备份/换机（导入为全量覆盖）、一键「重置」回同步默认；欧美台同步重建换源地址时，面板顶部会列出失配的个人调整供重新指定或清理
- **导入自己的列表**：右上「导入列表」选择 txt/m3u 文件即时加载
- **备份全部**：⚙ 面板「备份全部」打包收藏/维护配置/健康标记/歌曲历史/个人电台导出 `vradio-backup.json`（v3 格式，可勾选附带质量与收听统计数据）；恢复前先看覆盖预览，失败如实区分未提交/已回滚并给恢复路径
- 点播后等 5–10 秒属正常（直播流建流慢，非卡死）

## 开发与测试

零依赖是核心设计：只用 Node 内置模块 + 本地化的 hls.js，测试也不装任何依赖。`npm test` 是 L0–L5 分层测试总入口（方案见 [docs/testing-strategy-2026-11.md](docs/testing-strategy-2026-11.md)）：

```bash
npm test               # 总入口：契约键三侧比对 → 纯函数/fixture 各文件 → smoke 压轴（离线秒级）
npm run test:contract  # L0 定向：contracts/ 三侧键白名单 + 生成资产/manifest 一致性
npm run test:unit      # L1 定向：纯函数/状态机/fake browser（player/store/sync/logos/ui-* 等 30+ 文件，vm 沙箱不起长驻服务）
npm run test:api       # L2 定向：真服务矩阵（smoke/quality/listen-stats/myradio/station/np-proxy/sync-api）
npm run test:browser   # 正式页 Chromium PR 门（需 .ci/browser 独立 Playwright 工具目录，CI 自动安装）
npm run test:nightly   # 夜间层：故障注入 drills + 长时 soak（--real 加真实源抽样、--soak=N 调时长、--quick 只 drills）
```

lint/typecheck 无配置；改动先跑 `npm test` 烟雾回归，行为验证 = 启动服务后在浏览器里实际点播。Web/安卓两侧共同契约（radio.txt 行格式、`radio.*` 持久键白名单、备份 v3 schema）收敛在 `contracts/` 目录，改契约须两侧测试同步点名。

## 源的更新与维护

电台源是本项目的重中之重，流地址天然会漂移/下线。VRadio 用「双上游 + 三层感知」应对：

**双上游**

| 来源 | 内容 | 同步方式 |
|---|---|---|
| [gaotianliuyun/gao](https://github.com/gaotianliuyun/gao) | 国内 1400+ 电台（央广/地方/音乐/中国广播） | 一键同步直接拉取上游 radio.txt |
| [AlonDrilich/radio-playlists](https://github.com/AlonDrilich/radio-playlists)（Radio Browser 数据镜像） | 全球 top-500 高票电台 | 一键同步时过滤欧美国家 → **逐个实测**（4.5s 超时、需持续吐数据）→ 只保留活流 |

Radio Browser 官方 API 在国内直连不可达，走 GitHub 镜像 + api.github.com 拉取（并带 gh CLI 回退）。

**四层死链感知**

1. **同步时**：欧美音乐 / 国际新闻·谈话两分类每次整体实测重建，下线台自动消失；国内台按台名关键词重分类（无视上游分类头，对上游改版免疫）
2. **体检时**：「体检」按钮对当前列表逐台探测（服务端检测绕开 CORS），✓/✗ 可视化标记
3. **播放时**：多源自动切换——某台播不出会自动尝试它的其它地址（蜻蜓 m3u8 ⇄ mp3 直流 ⇄ 代理）
4. **用户层手动救援**：⚙ 维护面板给失效台**追加备选源**（探活通过才收），追加源随收藏/记忆按地址回绑，同步重建后依然生效

**命令行用法**（不开页面也能同步）：

```bash
npm run sync                 # = node update-sources.js，同步电台源（含台标随行更新）
npm run sync -- --logos      # 只重建 logos.txt 台标数据（数秒，不实测不改 radio.txt）
```

同步前会自动备份旧列表为 `radio.txt.bak`；`my-radio.txt` 为个人补充，永不被覆盖。

## 工作原理

### 1. 网络电台 = 一个永不结束的音频流 URL

所谓「听电台」，本质是把一个持续产生音频数据的 HTTP 地址交给 `<audio>` 播放。最基础的收音机只需一行：

```html
<audio src="http://lhttp.qingting.fm/live/273/64k.mp3" controls></audio>
```

### 2. 但现实有三道墙，VRadio 的三级播放策略逐一化解

| 层级 | 机制 | 说明 |
|---|---|---|
| ① MP3/AAC 直流优先 | `<audio>` 原生跨域播放 | 媒体元素播放**不需要** CORS 许可。蜻蜓 `lhttp.qingting.fm/live/{id}/64k.mp3` 是国内台最优解；遇到 `ls.qingting.fm/live/{id}.m3u8` 会自动换算成同 id 的 mp3 直流 |
| ② m3u8 直连 | hls.js (MSE) | 仅当 CDN 允许跨域时成功（部分海外台可以） |
| ③ 本地代理兜底 | `server.js` 的 `/proxy?url=` | 同源转发清单与分片（hls.js `xhrSetup` 把相对分片拼回远端 base），任何 CORS 限制都失效——央广 ngcdn CDN 实测必须走这条 |

每个电台按 ①→②→③ 依次尝试，全失败才报错。

### 3. 电台数据从哪来

`radio.txt` 来自开源项目 [gaotianliuyun/gao](https://github.com/gaotianliuyun/gao)，社区持续维护。格式极简：

```text
分类名,#genre#
电台名,http://流地址
电台名,http://备选地址
```

同名多行 = 同一电台的多个备选源（自动故障切换的基础）。更新列表：

```bash
gh api repos/gaotianliuyun/gao/contents/radio.txt --jq .content | base64 -d > radio.txt
```

## 实测记录与已知坑（2026-10，国内直连环境）

- ✅ 实测浏览器可播：Love Radio FM103.7（mp3 直流）、CNR 中国之声（代理 + hls.js）、动感 101 / 经典 947 / 东广新闻台 / 交通台 105.7（mp3 直流）、YES 933 / Class 95 新加坡（AAC 直流）、**Capital FM London（mp3 直流秒开）**
- ✅ 欧美台可用率：Radio Browser 全球 top-500 中 223 个欧美台实测 177 个直连可用（80%）
- ❌ **节目单（EPG）功能已移除（2026-10-12）**：实测蜻蜓 SSR 能取到的节目数据大多过时，欧美/海外台则完全无数据源，实用价值不抵维护成本——功能整体下线（实现与实测细节见 git 历史与 PR #4），boot 时会顺手清掉旧版本留在 localStorage 的 `radio.epg` 缓存
- ✅ **台标数据源实测（2026-10）**：蜻蜓频道页 `m.qtfm.cn/channels/{id}` 内嵌封面图（`<img class="img" src="…!200">`，200px 缩略，直连可加载）——按流 URL 确定性可取；`pic.qingting.fm/2013/channel_logo/{id}.jpg` 旧规律对 channel id 已 404（只对 radios 目录 id 有效）；欧美台走 Radio Browser 镜像 m3u 的 `tvg-logo`（当前覆盖 104/195 ≈ 53%，按流 URL 匹配）；Radio Browser `byurl` 接口的 favicon 作运行时兜底（镜像 de1 直连可用）
- ⚠️ Radio Browser 官方 API 镜像（`de1.api.radio-browser.info`）2026-10 起实测可直连（与旧记录「国内不可达」不符），但其数据按名字匹配我们 1600+ 台不可靠（仅欧美台有镜像属性），**概览富化不采纳**——列表概览信息以「体检状态 + 源数」为准
- ⚠️ **`live.xmcdn.com`（喜马拉雅 CDN）是假流**：返回 `206 / audio/aac` 但只有 336 字节，探活时勿信状态码，要按「持续吐数据」验收
- ⚠️ 蜻蜓 mp3 建流慢，点击后 5–10 秒出声属正常
- ⚠️ 流地址会漂移：某台播不了时先换源/点「同步源」重建，再怀疑代码
