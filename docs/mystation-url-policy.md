# `/api/mystation` 流地址长度策略

`POST /api/mystation` 对提交的流地址执行严格输入校验：去除首尾空白后，长度必须不超过 512 个字符；超长地址以 HTTP 400 拒绝，并且不会执行探活或写入 `my-radio.txt`。

服务端不再静默 `slice(0, 512)`。静默截断可能改变 URL 的查询参数、签名或路径，使探活对象与最终落盘对象不一致，并把一个看似可用的地址持久化为不可用地址。客户端仍可在提交前做提示，但服务端是最终边界。

长度以内的地址继续经过 `safeTarget`/`guardLookup`（测试注入缝除外）和既有探活流程；该策略不改变 12 秒探活窗口、重复检测、原子写入或 500 行/64KB 文件上限。
