# C3 离线证据结构与算术检查

仅用于检查自报数据的结构和算术，不联网、不监听、不生成候选、不发布、不写任何文件。`node tools/c3-evidence.js evidence.json` 输出 JSON 到 stdout；结构错误或算术不达标退出 1，读取/用法错误退出 2，算术通过退出 0 **不代表发布通过**。决策固定 `NO_GO`，即使填入声称已审核的字段也不会改变。输入 SHA-256 仅用于字节识别，不证明来源、许可、真人试听或直连真实性；不校验签名、时间真实性或身份权限。

## 输入结构（版本 1）

对象字段：`version:1`、同一固定上游 `commit` 与测量脚本 `scriptCommit`（小写 40 位十六进制）、`candidates:[{url,category}]`（精确 URL 唯一）、`mainUrls:[url]`（允许显式空数组）、非空 `releaseCategories:[分类]`、`rounds` 恰好两个，每项 `{window,commit,scriptCommit,results:[{url,code,latencyMs}]}`。每轮 URL 至多一条、属于候选；缺结果即未测。窗口是不同的非空标签，只检查不相等，**不证明真实时间或不重叠**。结果允许现有诊断枚举及 `EXCEPTION`；未知 code、负或非有限延迟、重复、坏 URL 和含凭据 URL 均为结构错误。所有数据都是声明，不应放敏感信息。工具不读取或检查 URL 地址，不连接流。

## 推荐算术约定及边界

既有 [C3 门禁](c3-recommended-radio-gate-2026-11.md)给出阈值，但未冻结所有分母；以下为本工具**显式推荐的可复核口径，不冒称原门禁已规定**：

- 每轮覆盖 = 有效结果行数 / 唯一候选数；每轮 survival = OK 行数 / 有效结果行数。未测不计成功或失败，但进入覆盖分母。
- 合并 survival = 两轮 OK 观察行数 / 两轮所有观察行数（观察加权，重复 URL 跨轮分别计）；合并 SHORT_BODY 同分母；NETWORK 和 EXCEPTION 单列，EXCEPTION 必须为 0。p95 用全部观察延迟、升序 nearest-rank `ceil(0.95*n)`；阈值 ≤6000ms。
- 精确重叠率 = 候选与主库的 URL 精确交集数 / 唯一候选数，不做 URL 归一化；真正新增 OK = 不在主库且任一轮 OK 的唯一候选 URL 并集。该数不代表两轮都稳定、长期可用、人工确认或内容合规。
- 同时报告两轮均 OK 的新增 URL 交集，仅描述这两次观察，不代表长期稳定。
- 每拟投放分类候选至少 20 个，分类 survival = 该类两轮 OK 观察数 / 该类两轮观察数，至少 60%。逐分类逐轮覆盖与缺测数只报告、不作为额外门；总体 90% 无法保证每类覆盖充分，稀疏分类须独立审查。分类来自候选的自报映射，不能证明中文映射质量。两轮覆盖均 ≥90%、单轮 survival ≥65%、合并 ≥70%、新增 OK ≥250、重叠 ≤10%、SHORT_BODY ≤10%。
- 本工具不支持分层抽样权重或包含概率，不得将抽样结果自动视为全量等价；需预注册抽样与单独审查。所有结果含失败和超时，延迟必填且应是实测耗时；本工具无法验证自报数字或超时设置。

结构校验不证实候选全集、主库清单完整性、固定 commit 真实存在或测量真的发生；两个不同时窗标签不能证明两个实际时间窗口。真人试听、每分类至少 3 台且总计至少 10 台、国内直连证明、许可/品牌、Web/Android 设备测试和可信身份均需独立证据审核；不额外规定必须人工审批。未来可由具备可信证据和授权的流程另行判断，本 CLI 不能作真实性判定。任何自报 `approved`、哈希或记录不能让该工具给出 GO。不得将 fixture、合成记录或算术通过当成真实试听或验收证据。

算术通过的进程退出码 0 仅表示检查成功，绝不能被 CI 当成发布授权：消费方须检查 `decision`，本工具始终为 `NO_GO`。此版本没有将证据与最终成品逐项绑定；尤其现有 sidecar 有 300 条截断，分类、许可和成品集合可能不同，须在真正投放前单独验证精确成品及映射。

CLI 只读单个不超过 8 MiB 的 `.json` 普通文件，拒绝最终路径的符号链接；无输出路径参数。大小上限仅适用于静态输入；检查与读取之间存在竞态，不能作为恶意并发修改时的资源限制。此检查不承诺抵御祖先链接或路径竞态，不构成生产文件系统安全边界。没有发布功能。
