# C3 v2 Android 离线解析实验

基于 #89 的 a6d63808d349e8c6fff689f246d311349798fb63；提案未冻结，实验代码只在 JVM 测试源集，不改变生产解析、网络、文件、UI 或开关。测试从共享 generated fixture 解码原始字节，检查完整输出、拒绝、边界和真实 SHA-256；pointer 的代选择与本地撤销结果仅为测试环境模拟，绑定 commit 为 fixture 注入，不是来源真实性证明。URL 仅检查格式，回环地址可合法通过，绝非 SSRF 防护。

## 与现有实现及规范的差异和限制

- 既有 v1 消费器不被复用或替换；实验解析器拒绝重复键、BOM、无效 UTF-8、非配对代理项、未知字段和不符合协议的数值，整代失败，不执行跳项或强制转换。
- JSON 数字仅接受可表示为 Long 的整数字面量，不接受 2.0 或指数形式；提案称整数但未明确数字字面量等价口径，须双端评审确认。parser 使用完整 ByteArray 入口，已检查长度但不提供有界流读取，因此不满足未来网络读取时立即中止的要求；未测试任意深嵌套的资源消耗，不能直接用于不可信生产数据。
- 实验中的远端同 commit 是外部参数，未实现可信 commit 的获取、固定路径、代的存在证明、连接安全、签名、撤销策略或本地缓存。模拟本地回退不等于实现它们；SHA 仅证明原始字节一致。
- 共享样本并不穷尽 URL/UTF-8 对抗；仅在本机 JVM 运行不代表 Android 设备、跨端一致性、来源/许可或真实试听已验证。C3 继续 No-Go，需独立安全评审与设备验证。
