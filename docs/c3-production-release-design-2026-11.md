# C3 安全生产发布设计（草案，默认 No-Go）

状态：设计提案，不是实现、发布授权或门禁通过证明。基线为 PR #73 的 `419f9777d12465b9a63ff51d238784d1372468b4`；仅讨论独立精选 sidecar，不改变主库及四生成资产、`/api/sync`、个人数据或 Android 契约。阈值及既有实测边界以 [C3 门禁](c3-recommended-radio-gate-2026-11.md) 为准；没有新增两轮证据、真人试听、许可核验或国内直连证明，**现在 No-Go**。下列机制均为待实现的建议，不是现有能力。

## 基线核实与威胁

- `discovery-publish.js` 的 `build(input, mainUrls)` 接受调用者提供的 `commit`、`ok` 和 `code`；`SOURCE`、`LICENSE` 是硬编码标签。格式正确不证明来源、探测、许可或真实授权。`publish(dir, raw)` 接受任意目录，`publishBusy` 仅限单进程；目录/文件符号链接、路径替换和跨进程并发未受防护，不能作为生产发布边界。
- 现有内容寻址代、manifest 字节数/SHA-256、`current`/`previous` 回退只提供一致性和有限损坏回退，不提供真实性或防恶意替换；单纯哈希和自报标签不可当签名或许可。`publish` 写两文件后 rename 指针，但无持久化协议，已有同名不完整代会被拒绝；`load` 指针本身不可读时直接返回空，不能声称必然恢复旧代。
- `discovery-sidecar.js` 显式说明 normalize 不证明来源许可；浏览器快照读取逐代校验且失败返回空，`app.js` 仅在 `FEATURES.discoverySidecar` 开启时加载。`test/discovery-publish.js` 仅在临时目录测试串行发布/损坏回退，fixture 自造成功字段，不是线上证据或跨进程/崩溃测试。
- 对手可提交任意候选和 JSON、替换工作目录内容、并发启动发布、预置符号链接或在检查后替换路径；哈希相符的恶意数据仍是恶意数据。假设发布主机管理员/内核和受控发布身份可信；管理员被攻陷、私钥泄露不在本地锁能解决的范围，应吊销授权并停止发布。

## 证据和自主决策：不可由输入自证

1. 将上游仓库身份固定在受控配置中，从可信来源固定 commit 获取原始清单及对应许可文件，保存原始字节、URL、获取时间、commit、文件路径和 SHA-256；验证 commit 对应内容及来源，拒绝调用者用任意字符串替代。代理依据真实材料核验许可文本、版本、适用范围（清单与每条流内容/品牌权利分开）、保留原件与审查结论；CC0 标签不等于流内容授权，不明则剔除或 No-Go。获取异常、缺件、不能验证、许可冲突一律失败关闭。安全捕获不得带访问令牌或私密地址入公开报告。
2. 受控运行器对固定候选集合及固定脚本版本运行两轮互不相同时间窗口的实际探活，归档原始逐 URL 结果、时间、脚本/配置/上游 commit、候选集哈希、环境及出口/直连证明、失败/超时和总数；运行器身份签名并由独立验证器验签，不能相信候选 JSON 自称 `ok`。签名证明产生者和字节未改，不证明测量或内容真实；需受控运行环境、审计及复核，缺信任根或可信时间/环境证明则 No-Go。
3. 代理按门禁文档独立复算两轮有效覆盖各 ≥90%、合并 survival ≥70%、单轮 ≥65%、新增且 OK ≥250、精确重叠 ≤10%、合并 p95 ≤6000ms、程序异常 0、SHORT_BODY ≤10%，每拟投放分类 ≥20 候选且 survival ≥60%；网络错误单列，分母及未测清楚列示，不可缩小样本凑门。确定分类及最终候选后，再核对每条候选身份与两轮证据及许可映射，发现变更须重评。
4. 真人在可证明国内直连环境，按每拟首发分类 ≥3 台且总计 ≥10 台的代表样本实际试听；记录人员、时间、环境证明、样本 URL/分类、可听与内容匹配、版权/品牌风险及失败原因，并签名归档。解码、自动探活不能代替真人；听取失败或样本不足阻断对应分类/发布。Web 与 Android 设备实测、可回滚演练同样须有记录。
5. 用户已授权代理依据预定推荐门槛自主记录 Go/No-Go，不额外要求人工审批或等待确认。决策记录须绑定代理身份、时间、范围、两轮证据包和真实试听/许可报告哈希、成品哈希、环境、有效期及一次性 nonce；受控发布身份验证记录完整性和权限并核销 nonce。候选、证据、许可、配置或成品任一变化均使决策失效；不得以调用者提供的 `approved:true` 或伪造 JSON 取代证据与门禁。真人试听目前尚未取得，必须由真实人员实际完成并留证，代理不得臆造或代称听过；在此之前仍为 No-Go。

## 工作流及固定边界

- **离线生成**：输入已归档证据，仅在隔离临时目录重现候选、校验 URL 与去重、主库排除和分类，生成内容确定性成品及证据引用；生成本身不写生产目录、不改指针、不触发发布，不把测试 fixture 视为证据。联网采证与离线构建分开；生成只读取已验证的不可变输入。
- **显式发布**：单独的受限操作、固定受管理员控制的生产根（例如部署配置内唯一绝对路径），不可从 CLI、HTTP、环境变量或输入 JSON 指定任意发布路径；授权的部署进程验全部证据和决策后，以成品摘要精准绑定发布。测试根只可在隔离测试二进制/注入接口中使用，生产构建不得启用。
- 根目录及全部祖先由可信管理员预建、限制所有者和写权限；发布者先验证根/祖先及锁对象不是链接或重解析点。仅使用锚定可信目录句柄的相对操作、逐层 no-follow/排除符号链接及硬链接、检查文件类型/所有权；所有 staging、代目录、指针均位于同一文件系统。拒绝路径穿越、异常文件类型和权限不安全。Node 14 内置 API 无法在所有平台完整提供此类无竞态句柄语义：实现前需选用经过审查的 OS 原语/隔离服务或在不支持的平台禁用生产发布；单纯 `realpath` 后再写会有 TOCTOU，不接受。Windows 重解析点与 POSIX symlink 分别验证。
- 用操作系统跨进程独占锁覆盖读取当前代、验权/消费授权、准备与提交的整个临界区；锁本身放可信目录、不可跟随链接，进程退出由 OS 释放。禁止仅靠 PID 文件、进程内变量或超时删除锁；不支持可靠锁/共享文件系统语义时禁止发布。锁内重验证决策和当前指针，必要时比较预期基线避免旧决策覆盖新代；竞争者失败或等待后重新验证，不得丢失更新。

## 提交、中断与回退

1. 锁内在可信根下创建独占、不可预测 staging 目录；写入完整数据、manifest 与受信证据引用，逐文件校验摘要/长度并持久化文件，再同步 staging 目录。不得修改现存内容寻址代；同名代只有完整且每字节匹配时复用，残缺或冲突隔离并停止，不能覆盖或当成功。
2. 在同一文件系统原子安装完整代并同步父目录；写新指针临时文件（current=新代、previous=已验证的旧 current），持久化临时文件后原子替换指针并同步父目录。操作失败不宣布成功，保留旧指针；首次发布无旧代时失败为空，不得清空主库。文件系统不保证所需原子性/持久性时 No-Go，明确区分进程中断与断电恢复。
3. 启动恢复仅在持锁、校验类型/摘要和授权后处理孤儿 staging；绝不能把未经门禁决策的孤儿提升为 current。当前代损坏时读者尝试已验证 previous；指针损坏时不能从任意目录猜最新代，须由可信、持久化的最后已知良好记录恢复，否则安全返回空并告警。回滚也须由代理基于证据自主记录明确决策、持锁、验证目标完整及仍被允许后原子切换；记录操作者、前后代与原因。读者不可见半代，发布失败或未知提交结果须先检查实际指针及审计记录，不能盲目重试。
4. 保留至少当前和上一已验证代及审计记录；清理需持同一锁、引用检查，不能跟随链接，不能删除读者仍可能使用的代。监控失败、损坏、回退、锁冲突、决策拒绝，默认关闭开关；任何异常停止扩大投放。

## 实施与验收测试（未来 PR 必须提供）

- 证据伪造：自填 `ok`/commit/license、伪签名、篡改原始字节、错上游、许可缺失或失效、重放 nonce、决策过期/权限不足、证据与成品不匹配，均拒绝；两轮缺失、窗口相同、分母不足、阈值边界、分类不足、真人/直连证明缺失均 No-Go。测试假签名和模拟监听只能测试门逻辑，不可充当真实审查。
- 安全路径：任意路径注入、`..`、祖先/代/锁/指针 symlink、Windows 重解析点、硬链接、路径替换竞态、权限异常和不支持的原语均拒绝；受保护路径外哨兵字节不变。
- 多进程：两个真实子进程竞争同一根、锁持有者被杀、陈旧决策及并发回滚，验证互斥、锁自动释放、指针无丢失更新，读者仅见完整旧代/新代；不以单进程测试替代。
- 中断故障：在每次写入、文件/目录同步、安装代、指针 rename 前后分别 kill，另注入 ENOSPC/EPERM、损坏与指针缺失；重启后验证旧代或完整新代、孤儿不自动发布、指针损坏安全空态及显式恢复。断电持久性须在支持目标文件系统的环境实测，不能由 kill 测试声称证明。
- 回归：离线生成不触碰生产目录和四资产哈希，失败不改主库/个人数据；客户端坏 current 回退 previous、均坏安全空、开关默认关闭；执行 `npm test`，并在未来实现 PR 记录受支持操作系统/文件系统、审计和 Web/Android 设备验收结果。

## 发布决策记录模板

记录候选和固定 commit、构建/证据摘要、两轮逐项指标及分母、许可审核与真人试听链接、国内直连证明、平台测试、风险和剩余项、决策代理/时间/记录完整性、发布环境/预期旧代、回退目标。任一项缺失或无法核实即 **No-Go**；本草案不预填真实值、不赋予发布许可。
